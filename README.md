# Carl Crayon — SRCcvde concept

Premium, mobile-first fitness creator website concept, built with React + Vite.

## Concept status
This is an **unofficial concept**, not an approved or launched website. Do not present it as an endorsement from Carl. It is excluded from search engines using a `noindex` meta tag, but **the public GitHub repo and any public deployment are not actually private**.

## Run locally
```bash
npm install
npm run dev
npm run build
```
